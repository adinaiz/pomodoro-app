# Pomodoro App - Focus Timer Project

Pomodoro App is a simple productivity timer that helps users focus using the Pomodoro method. The app lets users work for a set amount of time, take short breaks, and repeat the cycle to stay organized. I built this project with JavaScript and React to practice frontend development, component structure, state management, and user interaction. While building it, I worked on timer logic, button controls, and updating the screen when the timer changes. One challenge was making sure the timer started, paused, reset, and switched between work time and break time correctly. This project helped me understand how React state works in a real interactive app.

## Technologies Used

- JavaScript
- React
- HTML
- CSS
- Git / GitHub

## Project Features

- Focus timer
- Start, pause, and reset buttons
- Work and break time modes
- Simple user interface
- Real-time timer updates
